# Mr.Osama Ibrahim – اكتشف عالم الفيزياء

موقع ثابت (HTML/CSS/JS) جاهز للنشر على GitHub Pages.

## النشر
1. أنشئ مستودعًا جديدًا على GitHub وارفع كل الملفات.
2. من Settings ← Pages اختر Branch: main و Folder: / (root) ثم Save.
3. يظهر الرابط بعد دقيقة: https://USERNAME.github.io/REPO/

## التعديل
- الوحدات وروابط التواصل في أعلى ملف script.js.
- الألوان في أعلى ملف style.css.
